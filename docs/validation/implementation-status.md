## 实施裁决

- 使用新建工作目录直接开发，沿用既有分支；不创建重复 worktree。
- 用原生 PowerShell 维护执行账本，技能附带 Bash 帮助脚本在此 Windows 环境缺少 basename。
- 首次安装需要用户同意信任开发证书。在此之前继续完成可离线验证的实现与测试；不声称 WinRT 实机监听或锁屏已经验证。此顺序偏离“先验证首条锁屏链路再完整实现”，代价是适配层仍可能需要安装后调整。
- 初版 WPF 用单一组合窗口管理四页，规则、队列、平台、Windows 与本机 API 均分项目；未引入 MVVM 框架。若后续页面显著增加，再拆分 ViewModel。
- 首版数据库版本为 1，不存在旧版升级迁移；拒绝更高版本，不删除数据库。以后增加版本前须加入备份和迁移验证。
- 同步数据库接口用于单进程短事务，发送异步且每轮串行。由主程序单实例和忙碌门禁限制消费；CLI 仅只读配置，不运行崩溃恢复逻辑。
- 部分补充测试在实现后加入；不宣称全部 48 项都遵循了先红后绿。保留期边界与审查原子入口缺陷曾先观察失败后修复，审查后一次修复通过完整套件。
- 审查列出的 5 个问题均在修复范围内；历史信息可见性也已补充。审查未判断的真实平台、锁屏、安装与 UI 条件均保留为明确待验收，不静默丢弃。
